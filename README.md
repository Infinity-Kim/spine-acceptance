# Приёмка Spine

Страница для приёмки Spine-анимаций от дизайнера. Перетаскиваете экспорт и сразу видите, примет ли его рантайм, сколько он стоит в кадре и что вернуть на доработку.

Открыть: https://infinity-kim.github.io/spine-acceptance/

Всё работает в браузере, файлы никуда не отправляются. Сервера нет, страница статическая.

## Что умеет

- **Загрузка.** Zip, папка или файлы `.skel`/`.json` + `.atlas` + текстуры. Несколько наборов разрешений (1.0, 2.0) сравниваются между собой.
- **Два рантайма.** PixiJS 8.18.1 + spine-pixi-v8 и spine-webgl Web Player, на котором построен spine-threejs. Обе версии 4.2.119, переключаются на одной сцене.
- **Проверки с вердиктом.** Версия экспорта, binary или JSON, premultiplied alpha, размер атласа, лишние и недостающие регионы, пустая setup pose, клиппинг, draw calls, перерисовка. Текст замечаний для дизайнера собирается сам.
- **Профайлер.** Время CPU по фазам на последних 600 кадрах, худший кадр, тепловая полоса по каждой анимации, замер всех анимаций.
- **Причины draw calls.** Вкладка «Порядок отрисовки» показывает, на каком слоте и почему начинается новый вызов.
- **Отладка.** Кости, регионы, меши, треугольники, веса вершин, клиппинг, bounding box, пути, габариты, режим «альфа наоборот», треки с миксом, события, нагрузочный тест с копиями.
- **Прогноз по устройствам.** Замер пересчитывается на 8 телефонов, от Redmi 12 до iPhone 15 Pro Max.

## Насколько точен прогноз

**CPU.** Встроенный тест оценивает процессор в баллах Geekbench 6 single-core. Калибровка: Apple M5 Max в Chrome даёт 4200 баллов. Баллы телефонов взяты из публичных результатов Geekbench 6. Точность около ±25%.

**GPU.** Оценка грубая: площадь заливки делится на паспортную скорость заливки GPU с коэффициентом 0.5 на смешивание. Время GPU браузер не отдаёт.

Точнее всего замер на самом устройстве. Откройте страницу на телефоне, загрузите тот же экспорт и нажмите «Замерить все анимации». Скопированный замер вставьте на другом устройстве: он встанет в таблицу строкой «измерено».

## Сборка

Код страницы лежит в `src/template.html`. `build.py` вставляет стили Spine Web Player и собирает `index.html`:

```
python3 build.py
python3 build.py --embed путь/к/экспорту preview.html   # страница с уже загруженным экспортом
```

Библиотеки грузятся с CDN по точным версиям: PixiJS 8.18.1, spine-pixi-v8 и spine-player 4.2.119, JSZip 3.10.1.
